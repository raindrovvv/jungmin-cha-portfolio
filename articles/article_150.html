2차 위기 — Vercel 배포

우리는 웹 게임이었기 때문에Vercel로 배포하려고 했다.

문제는… 내가 Vercel 배포를 처음 해본다는 점.

Vercel: Build and deploy the best web experiences with the AI Cloud – Vercel

Vercel gives developers the frameworks, workflows, and infrastructure to build a faster, more personalized web.

vercel.com

여기서 병목이 발생했다.

  • Git 기본 브랜치가 main이 아니라 master
  • 급하게 세팅하면서 놓친 부분들
  • 브랜치 꼬임

그리고 처음에는 단순히 브랜치 문제라고 생각했다.하지만 Claude Code와 함께 로그를 뜯어보면서 원인이 더 명확해졌다.

그래서 아무리 GitHub에 push해도 반영이 되지 않았다.

Claude Code에게 현재 상황을 정리해서 던졌다.

  • GitHub에는 최신 코드 있음
  • Vercel은 Initial commit만 배포
  • 배포가 최신 커밋을 추적하지 않음

Claude가 바로 짚어준 포인트는 이것이었다.

"Git Integration이 연결되어 있는지 확인해라."

방법 A — Vercel CLI로 강제 배포 (가장 빠름)

cd 프로젝트폴더

npx vercel --prod

이 방법은 현재 로컬 코드를 바로 Vercel에 업로드한다.

Git 연결 여부와 상관없이 즉시 배포 가능하다.

방법 B — GitHub 연동 재설정 (근본 해결)

  • Vercel Dashboard → 프로젝트 선택
  • Settings → Git
  • Connect Git Repository
  • GitHub repo 선택
  • 기본 브랜치를 main으로 설정

연동 이후에는 push → 자동 배포가 정상 작동했다!!
